# Beetle OS 0.1.0-chat Release Notes

[Back to English docs](../README.md)

This release note records the audited change set from `0.1.0-espenhanced` to
`0.1.0-chat`. The implementation audit covered 41 commits from baseline
`2c666e31` through implementation head `41b0b4da`.

## Release Scope

- Migrated ESP storage terminology and runtime paths from SPIFFS-specific names
  to the storage/LittleFS model, including `storage_data`, state-root handling,
  fresh-filesystem directory creation, and config-save restart stability.
- Added the Configure UI chat surface: session listing, chat history, streamed
  replies, floating chat entry, safe Markdown rendering, explicit dialog close,
  route-pressure wording, and restart/reconnect recovery behavior.
- Reworked channel output semantics so plain outbound text is preserved by the
  QQ path and final reply formatting is governed by a single global output
  contract rather than sender-side repair logic.
- Refined model-source configuration surfaces, including provider/model display,
  source-list spacing, custom-header controls, and hidden internal source IDs.
- Rebuilt the Configure UI dashboard and status surfaces around system health,
  resource snapshots, route gating, pairing/config APIs, and new OS-style icon
  assets.
- Added route-worker, health, metrics, resource, API observability, and live-flow
  contract coverage for ESP and Linux deployment paths.
- Added the memory harness contract gate and L2 production replay coverage for
  memory behavior validation.
- Added Linux live-test flow scripts and strengthened ESP build, flash, channel,
  live-flow, and soak-analyzer contract tests.
- Updated product-facing documentation and README positioning for Beetle OS,
  LLM providers, memory, hardware, build scripts, and configuration APIs.
- Added Telegram reaction lifecycle support and tightened several channel,
  runtime, tool-registry, and write-back integration paths.

## Release Boundary

- The public branch target is `0.1.0-chat`.
- The audited comparison baseline is `0.1.0-espenhanced`.
