# Beetle OS 0.1.0-esp-real-time-voice 版本说明

[返回中文文档](../README.md)

本版本将 Beetle OS 从 `0.1.0-chat` 更新到
`0.1.0-esp-real-time-voice`。这个版本的重点是 ESP 实时语音体验：唤醒词、
麦克风输入、实时对话、语音播放和浏览器更新。

## 主要更新

- ESP32-S3 和 ESP32-P4 新增 WakeNet 唤醒词能力。
- 唤醒后可以进入实时语音会话，支持语音输入、服务端语音检测、语音回复播放和空闲退出。
- 新增 ES7210 输入和 ES8311 输出音频 codec 支持，并接入板型级音频总线配置。
- 配置 UI 新增语音链路相关的音频、I2C、总线和硬件配置校验。
- 浏览器固件包新增 WakeNet 模型产物，浏览器更新流程可以随固件一起写入模型分区。
- 新增 display HUD v2，用于展示设备状态、语音模式、资源状态和恢复状态。
- 优化 ESP 设备在语音会话期间的资源调度，降低语音、显示、后台写回和外部连接互相影响的概率。

## 唤醒与实时语音

本版本把 ESP 语音链路纳入产品构建。WakeNet 会从设备 flash 中加载随包发布的语音模型，通过板载麦克风监听唤醒词，并在唤醒后进入实时语音会话。

唤醒后，Beetle OS 会使用已配置的实时语音服务建立连接。设备会上传麦克风音频，播放返回的语音回复，并在对话空闲后自动退出语音模式。

## 浏览器烧录

浏览器固件包现在按板型提供分段更新文件：

- 应用固件
- bootloader
- partition table
- WakeNet 模型镜像

这意味着浏览器更新可以同时更新固件和 WakeNet 使用的语音模型。使用随包提供的浏览器更新流程时，不需要单独手动烧录模型。

## 升级说明

本版本新增 model 分区。从 `0.1.0-chat` 升级到本版本时，设备会跨过一次分区布局变化，因为 model 分区使用了旧 storage 尾部的一段空间。

用户应根据自己的升级目标选择烧录方式：

- 如果希望保留现有设备存储和配置，选择浏览器更新，用随包流程更新固件和 WakeNet 模型。
- 如果需要全新的分区布局，选择完整安装。完整安装会清空设备配置，安装后需要重新配网和重新配置服务。

执行完整安装前，请先备份或记录重要设备配置。

## 运行态与显示

语音会话期间，Beetle OS 会优先保障麦克风输入、实时连接和语音播放。部分后台写回、外部重连和重型显示刷新会延后处理，以减少实时语音被打断的概率。

display HUD v2 让设备在启动、配置、语音、恢复和正常运行阶段的状态更容易检查。

## 稳定性改进

本版本围绕 ESP 设备的语音和更新流程补充了稳定性保护：

- 浏览器更新包会携带 WakeNet 模型，避免固件和模型版本不一致。
- 终端烧录流程默认使用保留配置的更新方式。
- 完整安装需要明确选择，避免误清空设备配置。
- 语音会话期间会降低后台任务对实时语音链路的干扰。
- 设备状态和语音模式在显示面板上更容易确认。

## 兼容性

- 本分支为随包发布的 ESP 板型生成固件包，包括 ESP32-S3 和 ESP32-P4 profile。
- 实时语音需要配置可用的 realtime voice 服务，并保持设备网络可用。
- 文本通道、配置 UI、显示和记忆等既有产品能力仍保留在本版本中。
