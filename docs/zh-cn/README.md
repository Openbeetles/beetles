# 中文文档

[返回文档总索引](../README.md)

这里是中文文档目录。
普通用户先看“配置 / 工具 / 大模型 / 显示 / 硬件”，技术参考和开发文档放在后面。

| 文档 | 适合什么时候看 |
|------|----------------|
| [configuration.md](configuration.md) | 第一次配网、打开配置页、设置配对码 |
| [tools.md](tools.md) | 想知道 Beetle Agent OS 现在能做什么、会看到什么 |
| [llm-providers.md](llm-providers.md) | 配置大模型服务商、`api_url` 和切换顺序 |
| [display.md](display.md) | 配 SPI 屏幕和显示仪表板 |
| [hardware.md](hardware.md) | 看支持板型和常见硬件问题 |
| [config-api.md](config-api.md) | 自己写前端、脚本，或调用设备接口 |
| [hardware-device-config.md](hardware-device-config.md) | 写 `hardware.json` 并启用 `device_control` |
| [linux-release-rollback.md](linux-release-rollback.md) | Linux 版 Agent OS 的安装、打包和回滚说明 |
| [architecture.md](architecture.md) | 给开发者看的模块结构和扩展点 |

建议阅读顺序：

1. `configuration`
2. `tools`
3. `llm-providers`
4. `hardware`、`display`
5. 只有在集成或开发时再看 `config-api`、`hardware-device-config`、`linux-release-rollback`、`architecture`
