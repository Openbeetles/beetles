# 配置指南

[English](../en-us/configuration.md) | **中文** | [文档索引](../README.md)

这篇只讲第一次把 Beetle 用起来，不讲接口细节。

## 最短路径

第一次使用时，先完成这四件事：

1. 找到设备地址
2. 设置配对码
3. 让设备连上网络
4. 选一个大模型和一个聊天通道

## 先打开配置页

常见入口有两个：

- 第一次使用时，连接设备热点 **Beetle**，打开 `http://192.168.4.1`
- 如果设备已经在局域网里，直接打开它的局域网地址

仓库里的 `configure-ui` 也可以连接设备。

## 配对码是做什么的

配对码用来保护重要操作，比如：

- 保存配置
- 重启设备
- 恢复设置
- 在线升级

第一次打开配置页时就要设置，后面也会继续用到。

## 你最常会配置哪些东西

| 区域 | 用来做什么 |
|------|------------|
| 网络 | 让设备接入你的网络 |
| 大模型 | 让 Beetle 能理解和回复 |
| 聊天通道 | 让你能从聊天软件里使用 Beetle |
| 工作账号 | 让 Beetle 处理邮箱、日历、文档和联系人 |
| 硬件 | 让 Beetle 控制外设、读取传感器 |
| 显示 | 让 Beetle 把状态显示在屏幕上 |
| 音频 | 让 Beetle 支持语音输入输出 |

## 建议顺序

如果你只是先把 Beetle 跑起来，按这个顺序就够了：

1. 网络
2. 大模型
3. 聊天通道

下面这些都可以之后再补：

- 工作账号
- 硬件
- 屏幕
- 音频

## 常见问题

- 打不开配置页：先确认你连的是设备热点，或者已经在同一个局域网
- 保存失败：通常是配对码不对，或者页面已经过期，重新打开再试
- 能打开页面但不会回复：先检查大模型和聊天通道是不是都配好了
- 看不到邮箱、日历、文档这些能力：先确认对应账号已经接好
- 硬件没有反应：先确认设备已经配置，而且接线和配置一致

如果你要自己写页面或脚本，再看 [config-api.md](config-api.md)。
