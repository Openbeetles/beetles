# Beetle OS 能做什么

[English](../en-us/capabilities.md) | **中文** | [文档索引](../README.md)

Beetle OS 并非单一聊天机器人，也不是单一硬件运行时。
它将聊天交互、浏览器配置、大模型接入、办公账号能力与设备控制整合在同一运行时中。

## 典型应用场景

| 产品形态 | Beetle OS 在里面承担什么 |
|----------|-----------------------|
| 桌面助手 | 聊天、提醒、文档、轻量流程协助 |
| 前台设备 | 接待答疑、屏幕展示、访客分流、运营协助 |
| 提醒终端 | 周期提醒、简单日程、语音、通知 |
| 监测节点 | 传感器、阈值监控、告警投递 |
| 设备控制器 | GPIO、PWM、I2C 和简单执行流程 |

## 能力范围

### 聊天与任务

Beetle OS 可以通过支持的聊天通道接收输入、回复、主动发消息、管理提醒，并推动轻量任务流继续往前走。

### 办公与协作

接好办公账号之后，Beetle OS 可以处理邮箱、日历、联系人和文档。
适用于办公助手、前台终端与内部流程协作设备。

### 硬件与自动化

Beetle OS 可以控制已配置设备、读取传感器并监控阈值。
适用于监测节点、硬件控制器以及软硬件一体设备。

### 语音与屏幕

在音频和屏幕配置完整时，Beetle OS 可以说话、听音，并在屏幕上展示状态。
适用于桌面终端、提醒设备与固定交互硬件。

### 运维与诊断

Beetle OS 自带系统状态、诊断、定时任务和 Linux 发布管理能力。
当系统以长期运行的设备或主机服务形态部署时，该能力是基础要求。

## 平台适配

| 平台 | 更适合做什么 |
|------|--------------|
| ESP32-S3 | 常驻边缘设备、传感器、硬件控制 |
| ESP32-P4 | 更重一点的板端流程 |
| Linux | 更广的外部集成、更长时间运行、主机侧扩展 |
