# Beetle 配置前端

[English](README.md)

## 这是什么？

**Beetle Configure UI** 是 Beetle 设备的浏览器配置页。
你可以从设备地址打开，也可以从在线页面打开；只要浏览器能连到设备，就能完成配网和各项设置。

## 这页能做什么

连接 Beetle 设备后，可以在这里：

- 设置或修改 **配对码**（保存配置等写操作前必须设置）。
- 配置 **WiFi**（扫描、选择并连接）。
- 配置 **通道**：Telegram、飞书、钉钉、企微、QQ 频道、Webhook（Token、密钥、开关等）。
- 配置 **LLM**：API Key、模型、提供商、兼容接口 URL（如 Ollama）。
- 配置 **代理**、**搜索 Key** 等。
- 查看 **系统信息**、**重启**、**OTA**（若固件启用）、**恢复出厂**。

所有写操作都需正确配对码；页面会代为携带。

## 这页给谁看

- **普通用户**：直接看下面的“如何使用”，按步骤连设备并完成配置。
- **开发者**：可直接跳到 [开发者：本地开发与发布](#开发者本地开发与发布)。

## 普通用户：如何使用

### 前置条件（使用配置页之前必须满足）

以下两点**缺一不可**：

1. **已烧录 Beetle OS 固件的设备。**
   配置页只能与运行 **Beetle OS** 固件的设备通信。若尚未烧录固件，请先按**上级仓库的 README 或文档**完成固件构建与烧录。本配置页**不能替代**烧录好的设备。

2. **设备已上电且你的手机/电脑能访问到设备。**
   - **首次使用 / 设备尚未连你家 WiFi 时**：设备会开启 **WiFi 热点**，SSID 为 **Beetle**（无密码）。你的手机或电脑需**先连接这个热点**，然后打开 **http://192.168.4.1**（通常为此地址，某些情况下可能为其他地址如 172.16.42.1）。
   - **设备已配网并连上家里路由器后**：你的手机或电脑需与设备在**同一局域网**，使用路由器分配给设备的 IP。

**重要**：无论你是通过「设备地址」打开配置页，还是通过「在线地址」打开，**浏览器所在设备必须与 Beetle OS 设备在同一网络**（连接设备热点 Beetle，或与设备在同一局域网）。否则页面无法与设备通信。

---

### 方式一：在配置页中使用设备地址

把设备地址填入本 Configure UI 的 **「设备地址」**。设备根路径当前返回 API 清单 JSON，不再承诺提供内置 UI 或跳转入口。

**设备尚未连你家 WiFi 时（首次使用）：**

1. 设备上电 → 会开启热点 **Beetle**（无密码）。
2. 手机或电脑 **连接到 WiFi「Beetle」**。
3. 打开本 Configure UI，并在 **「设备地址」** 中填写 **http://192.168.4.1**（通常为此地址，某些情况下可能为其他地址）。

此时只有设备在该热点下。

**设备已连上你家 WiFi 时：**

- 在与设备**同一局域网**的浏览器中，把路由器分配给设备的 IP 填为 **「设备地址」**。

**首次打开配置页时**：在页面上设置 **6 位配对码**。配对码用于保护所有写操作；密钥仅保存在设备端。忘记配对码可在配置页使用 **恢复出厂**（需仍能打开配置页）。

---

### 方式二：使用在线地址打开配置页

从互联网打开同一套配置页（例如 **https://openbeetles.github.io/beetles/**）。如果要真正配置设备，你的浏览器仍然必须能访问到那台设备，也就是和设备在同一网络。

**使用在线地址时的完整步骤：**

1. **准备好设备**  
   - 在硬件上烧录好 Beetle OS 固件（若未烧录，请先参考上级仓库文档完成构建与烧录）。  
   - 设备上电。

2. **让手机或电脑与设备处于同一网络**  
   - **未配网时**：手机/电脑连接设备的 **Beetle** 热点（无密码）。  
   - **已配网时**：确保手机/电脑与设备在同一局域网（如同一台家用/办公室路由器）。

3. **打开在线配置页**  
   - 浏览器访问：**https://openbeetles.github.io/beetles/**

4. **在页面中填写设备地址**
   - 在配置页找到 **「设备地址」**（Device URL）输入框。
   - 连接设备热点时填 **http://192.168.4.1**（通常为此地址，某些情况下可能为其他地址）；同局域网时填路由器分配给设备的 IP。
   - 保存后，页面会向该地址请求设备 API。

5. **设置配对码并开始配置**  
   - 首次使用需在配置页设置 **6 位配对码**。  
   - 之后即可配置 WiFi、通道、LLM 等；所有写操作都会携带该配对码（由页面自动携带）。

**若页面提示无法连接设备**：请检查 (1) 设备已上电；(2) 你已连接 **Beetle** 热点或与设备在**同一局域网**；(3) 设备地址是否正确——连接热点时通常用 **http://192.168.4.1**（某些情况下可能为其他地址，如无法连接可尝试 http://172.16.42.1），同局域网时用设备在局域网中的 IP。

**仅想预览界面**：没有设备时也能打开在线页面看界面；但若要真正读取或修改配置，仍然需要设备，并且浏览器与设备在同一网络。

---

### 首次使用与配对码

- **首次访问**：在配置页设置 **6 位配对码**。用于保护保存配置、重启、OTA、恢复出厂等写操作；密钥仅保存在设备端。
- **忘记配对码**：在配置页使用 **恢复出厂**（需仍能打开配置页并执行该操作）。

更多说明可看上级仓库文档，优先读 `docs/zh-cn/configuration.md` 和 `docs/zh-cn/config-api.md`。

## 开发者：本地开发与发布

### 环境要求

- Node.js 20+  
- npm
- Rust 工具链（`rustup`、`cargo`）
- 当前系统对应的 Tauri 桌面依赖：<https://v2.tauri.app/start/prerequisites/>

### 命令

| 命令             | 说明               |
|------------------|--------------------|
| `npm ci`         | 安装依赖           |
| `npm run dev`    | 启动开发服务       |
| `npm run build`  | TypeScript + Vite 构建 |
| `npm run lint`   | 运行 ESLint        |
| `npm run preview`| 预览生产构建       |
| `npm run tauri dev` | 用 Tauri 桌面壳运行同一套 UI |
| `npm run tauri build` | 构建桌面壳安装包 |

### 本地开发

```bash
cd configure-ui
npm ci
npm run dev
```

本地开发时，请在能访问目标 Beetle 设备的浏览器中打开页面。

### 桌面壳

`configure-ui` 现在额外提供了一个最小化的 Tauri 桌面壳，代码位于 `src-tauri/`。
这个桌面壳**不会**改变现有产品功能，只是把当前 React/Vite 配置页原样包装成桌面应用；设备地址、配对码、配置读写和现有 API 流程都保持不变。

```bash
cd configure-ui
npm ci
npm run tauri dev
```

如需打包桌面版：

```bash
cd configure-ui
npm ci
npm run tauri build
```

### 设计与样式
